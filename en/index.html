WO-2601 Late-Delivery PredictionXGBOOST · LEAKAGE DETECTION · THRESHOLD ANALYSIS

An end-to-end ML pipeline over 180,519 orders. Three columns that are only filled in after delivery (Delivery Status, Days for shipping (real), shipping date) were detected and removed, taking the feature set from 53 to 25. With the leakage gone the baseline F1 is 0.39; hyperparameter and threshold tuning takes it to 0.71. Train 0.713 / test 0.714 — no overfitting. The threshold was measured at four points (0.35–0.55). Data ceiling: added features left F1 unchanged — the true drivers (weather, traffic, carrier reliability) are absent from the dataset.
